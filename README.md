Aplicação de consola em C# para gestão de contas bancárias.
Foi o meu primeiro projeto em C#, desenvolvido no âmbito do curso de Sistemas de Informação e Tecnologias de Programação.

Funcionalidades:
- Criar cliente
- Abrir Conta
- Depositar dinheiro
- Levantar dinheiro
- Ver extrato

Tecnologias:
- C#
- .NET


Como executar:

1. Clonar o repositório:
   git clone https://github.com/tonisousa07/GestaoBanco.git
2. Entrar na pasta do projeto:
   cd GestaoBanco
3. Executar:
   dotnet run
